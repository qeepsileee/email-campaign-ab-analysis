# Данные

Источник: Kevin Hillstrom, MineThatData E-Mail Analytics And Data Mining Challenge, 20 March 2008.

[Описание эксперимента](https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html)

[Исходный CSV](http://www.minethatdata.com/Kevin_Hillstrom_MineThatData_E-MailAnalytics_DataMiningChallenge_2008.03.20.csv)

Файл `raw/hillstrom.csv` сохранён без изменения строк. В нём 64 000 клиентов. По описанию автора клиенты случайно распределены между тремя группами, результаты измерялись две недели.

| Поле | Значение |
|---|---|
| recency | Месяцы с последней покупки |
| history_segment | Категория расходов за прошлый год |
| history | Расходы за прошлый год, доллары |
| mens | Покупал мужские товары за прошлый год, 0/1 |
| womens | Покупал женские товары за прошлый год, 0/1 |
| zip_code | Тип территории: Urban, Rural, Surburban |
| newbie | Новый клиент за последние 12 месяцев, 0/1 |
| channel | Канал прошлых покупок |
| segment | Назначенная экспериментальная группа |
| visit | Посещение сайта в период наблюдения, 0/1 |
| conversion | Покупка в период наблюдения, 0/1 |
| spend | Потраченная сумма в период наблюдения, доллары |

Написание `Surburban` оставлено как в источнике. Идентификаторов клиентов, дат отдельных покупок, количества заказов, себестоимости и стоимости рассылок нет. Поэтому здесь нет анализа по дням, среднего чека заказа или расчёта ROI.
